# Key IAM Concepts

## Trust Policy
Defines who is trusted to assume a role.

## AssumeRole
Provides temporary access instead of permanent permissions.

## Least Privilege
Users only receive the minimum required permissions.

## Explicit Deny
Deny policies override allow permissions.

## CloudTrail
Used for monitoring and auditing AWS activities.

## Role-Based Access Control (RBAC)
Permissions are assigned through roles instead of direct user access.
